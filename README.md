# Delícias de Ana Rosa: site

Este projeto é um único arquivo, `index.html`. Não tem build nem instalação.

## Como publicar na Vercel (sem terminal)

1. Entre em vercel.com e clique em **Add New > Project**.
2. Arraste esta pasta, ou importe um repositório do GitHub com estes arquivos.
3. Em **Framework Preset**, deixe "Other". Deixe **Build Command** e **Output Directory** em branco.
4. Clique em **Deploy**.

## Antes de publicar de verdade (checklist)

- [ ] **Nomes e fotos dos bolos:** confirme com a loja.

- [ ] **Teste no celular:** pedido pelo carrinho, formulário de encomenda e botões de WhatsApp.

## Como atualizar

- **Com GitHub:** altere o `index.html` no repositório. A Vercel publica sozinha.
- **Sem GitHub:** substitua o `index.html` e envie a pasta de novo no painel da Vercel.

## Domínio próprio (quando o cliente tiver o .com.br)

Em **Settings > Domains** no projeto da Vercel, adicione o domínio e siga as instruções de DNS.

## Observações

- O painel de produtos (para a dona adicionar e remover bolos) é um projeto separado. Ele não faz parte desta pasta.
- Este site ainda usa a lista de produtos fixa no código. Quando o painel estiver ligado, a lista vai vir do banco de dados.
